# Catalogs And Column Conventions

This directory contains the main cluster and galaxy matched catalogs used by
the richness and local-overdensity analyses. Some derived products are generated
by notebooks or MPI scripts and may not be committed to the repository because
they can be large.

## Recommended Inputs

### `bgs_clus_RM_gal_matched.pickle`

Galaxy-level matched BGS/redMaPPer table. This has one row per BGS galaxy
matched to a redMaPPer cluster environment.

Use this for:

- computing spectroscopic richness from BGS galaxies,
- inspecting cluster-member or projected-galaxy properties,
- generating cluster-level spectroscopic-richness products.

Important columns:

| Column | Meaning | Notes |
| --- | --- | --- |
| `ID` | redMaPPer cluster ID | Use as the cluster join key. |
| `LAMBDA` | redMaPPer richness | Fiducial redMaPPer richness column. |
| `RA_central` | cluster BCG/central RA | Use for cluster-centered apertures. Legacy alias: `RA_x`. |
| `DEC_central` | cluster BCG/central Dec | Use for cluster-centered apertures. Legacy alias: `DEC_x`. |
| `Z_SPEC_central` | spectroscopic redshift of the BCG/cluster center | Preferred redshift for physical annuli. Legacy alias: `Z_SPEC_x`. |
| `Z_LAMBDA` | redMaPPer photometric cluster redshift | Use only if BCG spectroscopic redshift is unavailable. |
| `RA_member`, `DEC_member` | redMaPPer member/projected galaxy coordinates | Do not use as cluster centers. Legacy aliases: `RA_y`, `DEC_y`. |
| `Z_BGS` | BGS galaxy redshift | Galaxy-level quantity. |
| `TARGETID` | DESI target ID | Galaxy-level identifier. |
| `flux_*_dered` | dereddened BGS fluxes | Used for magnitudes/colors. |

Cluster-level tables should be made from this table with `unique(..., keys="ID")`
only when one row per cluster is needed.

## Derived Richness Catalogs

### `rm_clusters_with_spec_richness.pickle`

Generated by:

```text
richness_relation/add_spec_richness.ipynb
```

Cluster-level table with one row per redMaPPer cluster and added
spectroscopic-richness columns.

Use this as the preferred input for DR9 local-overdensity calculations.

Important columns:

| Column | Meaning | Notes |
| --- | --- | --- |
| `ID` | redMaPPer cluster ID | Join key. |
| `RA_central` | BCG/central RA | Aperture center. Legacy alias: `RA_x`. |
| `DEC_central` | BCG/central Dec | Aperture center. Legacy alias: `DEC_x`. |
| `Z_SPEC_central` | BCG spectroscopic redshift | Preferred redshift for converting physical radii to angles. Legacy alias: `Z_SPEC_x`. |
| `LAMBDA` | redMaPPer richness | Compare against environment. |
| `lambda_spec_tot` | preferred spectroscopic richness | Use this for weighted spectroscopic richness comparisons. |

For future local-overdensity work, prefer:

```python
x_rm = table["LAMBDA"]
x_spec = table["lambda_spec_tot"]
ra = table["RA_central"]
dec = table["DEC_central"]
z = table["Z_SPEC_central"]
```

### `bgs_clus_RM_gal_matched_with_spec_richness.pickle`

Generated by:

```text
richness_relation/add_spec_richness.ipynb
```

Galaxy-level version of `bgs_clus_RM_gal_matched.pickle` with the cluster-level
spectroscopic richness copied onto each galaxy row.

Use this only when a galaxy-level table is needed but you also want access to
cluster-level richness columns.

## Clean Matched Catalogs And Luminosity-Function Weights

### `bgs_clus_RM_gal_matched_with_weights.pickle`

Generated by:

```text
make_catalogs/projection_match_catalogs.py
```

Galaxy-level BGS/redMaPPer matched catalog produced by the cleaned projected
matching workflow. This version uses `RA_central`, `DEC_central`, and
`Z_SPEC_central` as the cluster center and applies the projected aperture cut directly in
`h^-1 Mpc`. The same script reads the DA2 BGS Bright noveto catalog
`BGS_BRIGHT_full_noveto.dat.fits`, computes the geometric coverage fraction from
`BGS_BRIGHT_*_full.ran.fits` random catalogs in parallel with MPI, applies
cluster-level luminosity-function weights, and appends spectroscopic-richness
columns.

Important added columns:

| Column | Meaning | Notes |
| --- | --- | --- |
| `R_PROJ_HMPC` | Projected BGS-galaxy separation from the cluster center | Comoving `h^-1 Mpc`. |
| `DZ_CLUSTER` | `(Z_BGS - Z_SPEC_central)/(1 + Z_SPEC_central)` | Broad redshift sanity cut variable. |
| `central_flag` | BGS galaxy lies very close to the cluster center | Uses `R_PROJ_HMPC < 0.005`. |
| `RM_gal_flag` | BGS row is matched to a redMaPPer member-galaxy row | Matched by sky position and cluster `ID`. |
| `GEOMETRIC_FRACTION` | Geometric coverage fraction | Estimated from DESI randoms in the cluster aperture. |
| `angRad_deg` | Angular aperture radius | Corresponds to `1.5 h^-1 Mpc` at `Z_SPEC_central`. |
| `sq_deg` | Aperture area on the sky | In square degrees. |
| `N_random_total` | Total random count in the aperture | Summed over random catalogs. |
| `N_random_files_GEOMETRIC_FRACTION` | Number of random catalogs used | Useful for checking incomplete random reads. |

Run on NERSC:

```bash
cd /global/homes/z/zzhang13/DESI/Projection
source /global/homes/z/zzhang13/DESI/Projection/setup_nersc_mpi_myEnv_v39.sh
srun -n 8 -c 1 python make_catalogs/projection_match_catalogs.py
```

Outputs from the same script:

```text
catalogs/bgs_clus_RM_gal_matched_no_geometric_fraction.pickle
catalogs/rm_cluster_geo_fraction_1p5hmpc.pickle
catalogs/rm_cluster_geo_fraction_1p5hmpc.fits
catalogs/bgs_clus_RM_gal_matched_with_weights.pickle
catalogs/bgs_clus_RM_gal_matched_with_weights.fits
```

Important added columns:

| Column | Meaning | Notes |
| --- | --- | --- |
| `logL_lim_lf` | Luminosity limit implied by the apparent magnitude limit | Evaluated at `Z_SPEC_central`. |
| `logL_ref_lf` | Reference luminosity limit | Default is the limit at `z=0.1`, not below the LF fit limit. |
| `lf_log10_L_star` | Best-fit Schechter `\log_{10}L_*` used for the correction | Same value for all rows. |
| `lf_alpha` | Best-fit Schechter faint-end slope used for the correction | Same value for all rows. |
| `lf_observed_fraction` | Fraction of the reference LF observable at that redshift | Capped at 1 when already complete to the reference limit. |
| `LF_WEIGHT` | Cluster-level LF completeness weight | Same for all galaxies in a cluster. |
| `COMP_WEIGHT` | DESI/BGS completeness weight | `1 / PROB_OBS`; may vary galaxy by galaxy. |
| `GEOMETRIC_WEIGHT` | Geometric aperture correction | `1 / GEOMETRIC_FRACTION`, same for all galaxies in a cluster. |
| `TOTAL_WEIGHT` | Total richness weight | `COMP_WEIGHT * GEOMETRIC_WEIGHT * LF_WEIGHT`. |

## DR9 Local-Overdensity Outputs

These are written under:

```text
local_overdensity/dr9_outputs/
```

The current radius-grid MPI workflow writes to:

```text
local_overdensity/dr9_outputs/radius_grid_overdensity/
```

Main files:

| File | Meaning |
| --- | --- |
| `rm_dr9_radius_grid_overdensity.fits` | Main long-format output table. One row per cluster per radius definition. |
| `rm_dr9_radius_grid_overdensity.ecsv` | ECSV version of the same table. |
| `rm_dr9_radius_grid_overdensity_summary.ecsv` | Correlation summary table. |
| `radius_definitions.ecsv` | Radius definitions used in the run. |

Important columns in `rm_dr9_radius_grid_overdensity.fits`:

| Column | Meaning |
| --- | --- |
| `radius_def_id` | Integer ID for the signal/background annulus definition. |
| `radius_label` | Human-readable annulus label. |
| `r_sig_in_hmpc`, `r_sig_out_hmpc` | Signal annulus limits in `h^-1 Mpc`. |
| `r_bg_in_hmpc`, `r_bg_out_hmpc` | Background annulus limits in `h^-1 Mpc`. |
| `N_signal` | DR9 photometric galaxy count in the signal annulus. |
| `N_background` | DR9 photometric galaxy count in the background annulus. |
| `area_signal_deg2`, `area_background_deg2` | Geometric angular annulus areas. |
| `covered_area_signal_deg2`, `covered_area_background_deg2` | Estimated area covered by the DR9 sweep footprint. |
| `coverage_signal`, `coverage_background` | Covered fraction of each annulus. |
| `Sigma_signal_covcorr` | `N_signal / covered_area_signal_deg2`. |
| `Sigma_background_covcorr` | `N_background / covered_area_background_deg2`. |
| `Sigma_excess` | `Sigma_signal_covcorr - Sigma_background_covcorr`. |
| `N_excess` | `Sigma_excess * area_signal_deg2`. |
| `n_files_touching_cluster` | Number of sweep files whose bounding boxes overlap the cluster aperture. |

For correlation plots, the preferred environmental quantity is usually:

```python
y = table["Sigma_excess"]
```

and the preferred richness columns are:

```python
x_rm = table["LAMBDA"]
x_spec = table["lambda_spec_tot"]
```

## DR9 Sweep File Paths

Use the DR9 `9.0` sweep directories explicitly:

```python
SWEEP_DIRS = [
    Path("/global/cfs/cdirs/cosmo/data/legacysurvey/dr9/north/sweep/9.0"),
    Path("/global/cfs/cdirs/cosmo/data/legacysurvey/dr9/south/sweep/9.0"),
]
```

Do not use the broader south path:

```text
/global/cfs/cdirs/cosmo/data/legacysurvey/dr9/south/sweep
```

because that can include other sweep versions and produce inconsistent
footprints/counts.

## Column Rules Of Thumb

- Use `ID` for cluster-level joins.
- Use `RA_central`, `DEC_central` as the cluster BCG/central position.
- Use `Z_SPEC_central` for physical projected radii whenever available.
- Use `LAMBDA` for redMaPPer richness.
- Use `lambda_spec_tot` for the preferred weighted spectroscopic richness.
- Legacy notebooks may still contain `RA_x`, `DEC_x`, `Z_SPEC_x`, `RA_y`,
  `DEC_y`, and `Z_SPEC_y`; prefer the `_central` and `_member` names in new code.
- Do not use `RA_member`, `DEC_member` as cluster centers; those are
  galaxy/member-level positions.
- For local overdensity, diagnose edge problems with `coverage_signal`,
  `coverage_background`, and `n_files_touching_cluster` before interpreting
  zero counts physically.

Run:

```text
richness_relation/add_spec_richness.ipynb
```

Outputs:


Run on NERSC:

```bash
srun -n 16 -c 1 python local_overdensity/DR9_radius_grid_overdensity_mpi.py --no-r-mag-limit
```

```bash
srun -n 16 -c 1 python local_overdensity/DR9_radius_grid_overdensity_mpi.py --r-mag-limit 19.5
```
